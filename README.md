## 🌟 وصف المشروع

تم بناء **CV Builder Pro** ليكون حلاً احترافياً للمستخدمين والباحثين عن عمل في شتى المجالات (إدارية، تقنية، طبية، أكاديمية، إبداعية). يركز النظام على التخلص من المشاكل الشائعة في أدوات الـ CV التقليدية، مثل قص النصوص في أسفل الصفحة، اختفاء الصور أو الأيقونات عند الطباعة، أو حشر جميع المعلومات قسراً في صفحة واحدة.

## 🖨️ حل مشكلة الطباعة وPDF والصفحات المتعددة

### المشكلة الشائعة سابقاً:
* قص نصوص الخبرات أو التعليم في منتصف السطر عند نهاية الورقة.
* ظهور عنوان القسم منفرداً في أسفل الصفحة 1 وباقي محتواه في صفحة 2.
* اختفاء خلفيات الألوان والأيقونات والصور في الـ PDF.
* ظهور صفحات بيضاء فارغة بسبب ارتفاعات غير محسوبة.
* تحجيم الـ CV بالكامل وضغطه قسراً في صفحة واحدة ليصبح الخط صغيراً جداً وغير مقروء.

### كيف تم حلها جذرياً في هذا المشروع؟
1. **نظام التدفق الطبيعي A4 (Continuous A4 Multi-Page Flow):**
   - تم ضبط ورقة السيرة بعرض A4 القياسي (`210mm`) مع إزالة أي تحديد ثابت للارتفاع (`min-height: 297mm; height: auto !important;`).
   - يتمدد المستند تلقائياً إلى صفحة واحدة، صفحتين، 3 صفحات أو أكثر بحسب كمية البيانات التي يدخلها المستخدم.
2. **منع تقسيم العناصر الفردية (Avoid Inside Break):**
   ```css
   .cv-block-item,
   .cv-skill-item,
   .cv-lang-item,
   .cv-photo-wrapper,
   .cv-header,
   .cv-contact-item {
     break-inside: avoid !important;
     page-break-inside: avoid !important;
   }
   ```
   هذا يضمن أن بطاقة الوظيفة أو المؤهل التعليمي تنتقل كاملة بسلام إلى الصفحة التالية إذا لم تكن هناك مساحة كافية لها.
3. **ربط العناوين بمحتواها (Keep Headings with Next):**
   ```css
   .cv-section-title {
     break-after: avoid !important;
     page-break-after: avoid !important;
     break-inside: avoid !important;
   }
   ```
   يمنع ظهور عنوان القسم يتيماً في ذيل الصفحة.
4. **دقة الألوان والرسومات:**
   ```css
   -webkit-print-color-adjust: exact !important;
   print-color-adjust: exact !important;
   color-adjust: exact !important;
   ```
   يحافظ على الألوان والخلفيات والحدود والوسوم كما هي في المعاينة تماماً.
5. **ميزة فواصل صفحات A4 التقديرية (A4 Page Guides):**
   - زر خاص في شريط المعاينة يتيح للمستخدم رؤية خطوط تقريبية لنهاية كل صفحة A4 (عند 297mm و 594mm) لمعاينة مكان فواصل الصفحات قبل الطباعة.

## 🎨 القوالب الـ 15 المتمايزة

يضم المشروع 15 قالباً مختلفاً حقيقياً (في الهيكل والتخطيط وتوزيع الأعمدة، وليس مجرد تغيير ألوان):

1. **`01 — Professional` (الرسمي الاحترافي):** ترويسة علوية عريضة مع خطوط تنظيمية رصينة للشركات والجهات الحكومية.
2. **`02 — Modern` (العصري الجانبي):** شريط جانبي للمعلومات والمهارات واللغات، ومساحة واسعة للخبرات.
3. **`03 — Minimal` (المينيمال الهادئ):** مساحات بيضاء واسعة، بدون ألوان ثقيلة، مريح جداً للقراءة والفرز.
4. **`04 — Executive` (الإداري التنفيذي):** ترويسة داكنة بارزة ذات هيبة قيادية وإطارات فخمة للمدراء والتنفيذيين.
5. **`05 — Creative` (الإبداعي المبتكر):** لمسات بصرية وتدرجات لونية وشارات حيوية للمصممين ومبتكري المحتوى.
6. **`06 — Elegant` (الأنيق الراقي):** خطوط رشيقة، محاذاة مركزية متوازنة، وفواصل كلاسيكية ناعمة.
7. **`07 — Corporate` (المؤسسي الشبكي):** عناوين مربعة بارزة وتنظيم شبكي صلب ملائم للشركات الكبرى.
8. **`08 — ATS Friendly` (أنظمة الفرز ATS):** تصميم أحادي العمود نقي 100% بدون أي تداخلات أو أيقونات معقدة لتمرير الفحص الآلي.
9. **`09 — Designer` (المصمم التفاعلي):** شريط داكن عالي التباين وتركيز واضح على روابط الأعمال والمعارض.
10. **`10 — Tech & Dev` (التقني والمطورين):** مستوحى من بيئات التطوير، يبرز المهارات التقنية والتقنيات والمشاريع البرمجية.
11. **`11 — Academic` (الأكاديمي والباحثين):** تركيز عميق على المؤهلات العلمية، الأبحاث، والنشر والشهادات.
12. **`12 — Classic Standard` (الكلاسيكي الموثوق):** التنسيق التقليدي الأصيل المتعارف عليه لدى جميع مسؤولي التوظيف.
13. **`13 — Two Column` (العمودين المتوازنين):** توزيع متكافئ للبيانات في عمودين لاستغلال المساحة بانسيابية.
14. **`14 — Clean Slate` (النظيف الحاد):** خطوط حدية فائقة الوضوح مع مساحات تنفس ممتازة.
15. **`15 — Premium Gold` (الملكي الفاخر):** شريط ترويسة ملكي ولمسات أنيقة تعكس الخبرة الطويلة.

## 🛠️ طريقة إضافة قالب جديد

لإضافة قالب جديد إلى الموقع، اتبع 3 خطوات بسيطة:

1. **تسجيل القالب في كود `script.js`:**
   في مصفوفة `TEMPLATES_CATALOG`:
   ```javascript
   {
     id: 'tpl-custom',
     name: '16 — Custom Template',
     nameAr: 'القالب المخصص الجديد',
     tag: 'creative',
     badge: '16',
     desc: 'وصف مختصر لشكل القالب ومزاياه'
   }
   ```

2. **إضافة أنماط الـ CSS في `style.css`:**
   ```css
   .cv-document.tpl-custom {
     padding: 22mm 18mm;
     /* تخصيص الترويسة والعناوين والحدود */
   }
   .tpl-custom .cv-name {
     font-size: 2.2em;
     color: var(--cv-primary);
   }
   ```

3. **تحديد أسلوب الرندرة (اختياري):**
   إذا كان القالب يعتمد على تصميم أعمدة جانبي أو شريط علوي، قم بتوجيهه في دالة `renderLivePreview()` إلى دالة البناء المناسبة (مثل `buildSidebarTemplate` أو `buildStandardTemplate`).

## 🌍 طريقة إضافة لغة جديدة وترجمات الأقسام

1. **إضافة اللغة إلى `LANGUAGES_META` داخل `script.js`:**
   ```javascript
   el: { name: 'Greek', native: 'Ελληνικά', dir: 'ltr', font: 'Roboto, sans-serif' }
   ```
2. **إضافة ترجمات أقسام الـ CV في كائن `CV_TRANSLATIONS`:**
   ```javascript
   el: {
     summary: 'Επαγγελματικό Προφίλ',
     experience: 'Επαγγελματική Εμπειρία',
     education: 'Εκπαίδευση',
     skills: 'Δεξιότητες',

     courses: 'Πιστοποιήσεις',
     projects: 'Έργα',
     additional: 'Επιπλέον Πληροφορίες',
     contact: 'Επικοινωνία',
     present: 'Σήμερα',

     references: 'Συστάσεις διαθέσιμες κατόπιν αιτήματος',
   ```

## 🎨 طريقة تعديل الألوان والخطوط وCSS

- **نظام الألوان:** يحتوي التطبيق على 4 عناصر تحكم في الألوان:
  - `primaryColor` (اللون الرئيسي للترويسة والعناوين والشارات).
  - `secondaryColor` (اللون الثانوي للتمييز والتدرجات).
  - `textColor` (لون النصوص وفقرات المحتوى).
  - `bgColor` (لون خلفية الورقة).
- **طرق عرض المهارات الستة:**
  1. `tags` (وسوم وشارات ملونة).
  2. `dots` (نقاط ومستويات 1 إلى 5).
  3. `bars` (أشرطة تقدم ونسب مئوية).
  4. `stars` (نجوم التقييم ★).
  5. `levels` (نصوص المستويات).
  6. `list` (قائمة نقطية بسيطة ملائمة للـ ATS).
- **إعادة ترتيب الأقسام:** يمكن للمستخدم عبر أسهم الرفع والخفض تقديم قسم التعليم على الخبرات أو العكس فورياً دون أي إعادة كتابة.

## 📄 إرشادات حفظ PDF والطباعة

للحصول على أعلى دقة طباعة بدون أي قص:
1. انقر على زر **"تحميل PDF / طباعة"**.
2. ستفتح نافذة الطباعة الخاصة بالمتصفح:
   - **الوجهة (Destination):** اختر **"حفظ بتنسيق PDF" (Save as PDF)**.
   - **حجم الورق (Paper Size):** تأكد من اختيار **A4**.
   - **الهوامش (Margins):** اختر **"افتراضي" (Default)** أو **"بلا" (None)**.
   - **خيارات هامة:** فعّل خيار **"رسومات الخلفية" (Background Graphics)** لتظهر ألوان وتدرجات القالب.
3. اضغط **حفظ (Save)**.

## 🔒 نظام حفظ البيانات والتصدير والاستيراد

* **حفظ تلقائي (Auto-Save):** يتم حفظ كل حركة كتابة فورياً في `localStorage` باسم مفتاح `cv_builder_pro_v2_store`.
* **تصدير نسخة احتياطية (Export JSON):** تحميل ملف نصي يحتوي على جميع البيانات والتخصيصات بضغطة زر.
* **استيراد ملف (Import JSON):** رفع ملف JSON سابق لاستعادة كامل البيانات في ثوانٍ مع فحص أمني لسلامة المحتوى.
* **أمان وخصوصية 100%:** البيانات لا تغادر حاسوبك على الإطلاق ولا توجد أي استدعاءات لخوادم خارجية.
