# مُولّد واستوديو السيرة الذاتية الاحترافي (Pro CV & Resume Studio)

تطبيق ويب متقدم واحترافي لتصميم وبناء سير ذاتية بمعايير الشركات العالمية (ATS-Friendly)، يدعم **جميع اللغات العالمية** مع واجهة مستخدم متعددة اللغات (العربية، الإنجليزية، الفرنسية، الإسبانية، الألمانية، والتركية)، ويتيح تخصيص الهوية البصرية والقوالب، والمعاينة الحية لصفحة A4 القياسية، والتصدير المباشر كملف PDF عالي الدقة.

يتكون المشروع من **4 ملفات فقط** وبدون أي متطلبات أو مكتبات خارجية ثقيلة (Pure HTML5, CSS3, Vanilla JS).

---

## 📁 هيكلية ملفات المشروع (4 ملفات فقط)

```text
cv-builder/
├── index.html   # هيكل الواجهة، واجهة المحرر متعددة اللغات، ولوحة المعاينة التفاعلية
├── style.css    # نظام التصميم الاحترافي، 5 قوالب فاخرة، وتنسيقات الطباعة الدقيقة A4
├── script.js    # محرك الترجمة (i18n)، إدارة الحقول، القوالب، الحفظ التلقائي، والـ PDF
└── README.md    # الدليل والتوثيق الشامل للتطبيق
```

## 🌍 دعم جميع اللغات (Multi-Language & World Languages)

1. **واجهة مستخدم بـ 6 لغات عالمية (i18n):**
   - 🇸🇦 العربية (Arabic - RTL)
   - 🇬🇧 الإنجليزية (English - LTR)
   - 🇫🇷 الفرنسية (Français - LTR)
   - 🇪🇸 الإسبانية (Español - LTR)
   - 🇩🇪 الألمانية (Deutsch - LTR)
   - 🇹🇷 التركية (Türkçe - LTR)
2. **قائمة اللغات العالمية (World Languages Datalist):**
   - دعم اقتراح وإدخال أي لغة في العالم مع مستويات الإتقان القياسية (اللغة الأم، طليق، C2, C1, B2, B1, A2, A1...).
3. **دعم كامل للاتجاهين (RTL / LTR):**
   - زر تبديل فوري لتنسيق محتوى السيرة باللغة العربية (من اليمين لليسار) أو باللغات اللاتينية (من اليسار لليمين).

## 🎨 المظهر الاحترافي وخيارات التخصيص

* **5 قوالب تصميم عالمية تناسب مختلف التخصصات:**
  1. **Modern Tech (عصري تقني):** خطوط نظيفة مع شريط عناوين مميز ومناسب لمهندسي البرمجيات والتقنية.
  2. **Executive Pro (تنفيذي جانبي):** تقسيم عمودي ثنائي فاخر بلون داكن لأصحاب الخبرات الطويلة والإداريين.
  3. **Minimal Swiss (بسيط سويسري):** بساطة راقية تركز على المحتوى والمساحات البيضاء.
  4. **Academic Classic (أكاديمي كلاسيكي):** خطوط سيريف كلاسيكية (Merriweather) ملائمة للأكاديميين والمحامين والباحثين.
  5. **Creative Studio (إبداعي ملون):** شريط علوي بتدرج لوني أنيق للمصممين والمسوقين والمبدعين.
* **استوديو معاينة حقيقي (Studio Canvas):**
  - خلفية مسرح مظلمة حديثة شبيهة بأدوات التصميم الاحترافية (مثل Figma).
  - محاكاة دقيقة لأبعاد ورقة A4 (`210mm × 297mm`) مع ظلال واقعية.
  - شريط تحكم عائم للتكبير والتصغير والملاءمة (Zoom Controls).
* **اختيار الخطوط والألوان:**
  - دعم 4 خطوط احترافية: Cairo, Inter, Poppins, Merriweather.
  - لوحة ألوان سريعة مع منتقي ألوان مخصص (`Color Picker`).

## 🖨️ التصدير كملف PDF عالي الجودة

عند النقر على زر **"تصدير PDF / طباعة"**:
1. اختر في خانة الوجهة (Destination): **"Save as PDF"** أو **"حفظ بتنسيق PDF"**.
2. في الإعدادات المتقدمة:
   - حجم الورق (Paper size): **A4**.
   - الهوامش (Margins): **None (بلا)**.
   - تفعيل خيار **Background graphics (رسومات الخلفية)**.
3. اضغط على **حفظ (Save)**.
